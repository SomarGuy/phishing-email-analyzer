Phishing Email Analyzer: a standard-library Python tool that ingests .eml and mbox files and statically analyses them without ever opening or executing anything. It parses headers (Received-chain hop analysis, From/Reply-To/Return-Path mismatches, Message-ID and date anomalies, display-name spoofing), evaluates SPF/DKIM/DMARC from Authentication-Results plus an offline SPF evaluator over synthetic DNS fixtures, analyses URLs (punycode/homograph and edit-distance lookalikes, shorteners, IP and userinfo tricks, display-text vs href mismatch) and attachments (hashes, magic-byte vs extension, double extensions, macro Office types, archives containing executables via the ZIP directory, HTML smuggling), and scans for urgency, credential, gift-card and BEC wording. Each message gets a transparent weighted 0-100 score mapped to MITRE ATT&CK, a verdict (benign / suspicious / likely phishing), response steps, defanged IOC exports (CSV/JSON) and a one-page help-desk incident report with a copy-ready ticket note. A static dark-theme dashboard adds hop diagrams, score breakdowns and a client-side paste-a-raw-email analyser that never fetches anything. The 36-message corpus is clearly labelled synthetic, with a tuning set and a holdout written after the weights were frozen, and the self-graded evaluation honestly reports one false positive and one miss; the project has 334 pytest tests.
